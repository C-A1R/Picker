# Picker

Десктопное приложение для автоматизации сборки и объединения разрозненных PDF-документов в единые результирующие файлы по заданным правилам.

Программа позволяет сканировать выбранные каталоги и подкаталоги, гибко настраивать порядок склейки файлов и автоматизировать рутинную работу с документацией.

## 🛠 Технологический стек

* **Язык программирования:** C++11 / C++14
* **Графический интерфейс:** Qt 5 / Qt 6 (Qt Widgets)
* **Система сборки:** qmake (файл конфигурации `Picker.pro`)
* **База данных:** SQLite / Qt SQL (компонент `SqlMgr` для сохранения конфигураций и путей)
* **Работа с PDF:** Интегрированная сторонняя библиотека `PDFWriter` (C++ библиотека для генерации, парсинга и манипуляции PDF-структурами)

## 🚀 Основной функционал

* **Сканирование директорий:** Рекурсивный поиск PDF-файлов в отмеченных каталогах и подкаталогах.
* **Кастомная сортировка:** Настройка точного порядка объединения исходных документов.
* **Менеджер настроек:** Сохранение путей, параметров сессии и конфигураций сборки в локальную базу данных.
* **Интегрированный проводник:** Удобный встроенный виджет файлового менеджера (`FileExplorerWidget`) для быстрой навигации по системе.
* **Управление проектами:** Возможность группировать задачи на сборку документов через специализированный интерфейс (`ProjectWidget`).

## 📐 Архитектура репозитория

Проект имеет модульную структуру компонентов интерфейса и бизнес-логики:
* `FileExplorerWidget/` — Кастомный графический виджет для работы с файловой системой и выбора исходных PDF.
* `ProjectWidget/` — Виджет управления проектами сборки и очередями файлов.
* `PDFWriter/` / `PdfBuilder/` — Внутренние модули, отвечающие за низкоуровневую работу с PDF, компоновку страниц и генерацию итоговых документов.
* `SqlMgr.cpp` / `SqlMgr.h` — Слой работы с базой данных (сохранение настроек приложения и структуры проектов).
* `Settings.cpp` / `Settings.h` — Менеджер конфигураций и пользовательских параметров.
